# final-year-project-napier
A learning app for people that want to learn about fair division in game theory, using visualisations and real life examples
This project was made using python in pycharm 2025.3.3
Launching the software through the main will bring up a launch panel where you can open the cake cutting visualisations or the chore division real life example
